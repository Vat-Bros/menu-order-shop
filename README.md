# 🛒 Menu Order Web App

A simple static web application for restaurant menu ordering.  
Users can browse food items, view images, add items to cart, and see total price in real time.

---

## 🚀 Features

- 📋 Display menu items in a responsive grid  
- 🖼 Browse menu photos manually in a full-screen viewer with swipe navigation and zoom controls
- ➕ Add items to cart  
- ❌ Remove items from cart  
- 🔢 Quantity auto-increment when adding same item  
- 💰 Auto calculate total price  
- 📱 Mobile-friendly layout  

---

## 🛠 Technologies Used

- HTML  
- CSS  
- JavaScript (Vanilla JS – No framework)

## ▶ How to Run

---
1. Clone the repository

```bash
git clone https://github.com/your-username/menu-order.git
```

---

2. Open the project folder

```bash
cd menu-order
```

3. Open `index.html` in your browser

No server required – it runs as a static website.

---

## 📸 Usage

* Click **Add to Cart** to add an item
* Click **✕** to remove an item
* Click on any image to view larger preview

---

## 🧩 Customization

To add more menu items, edit the `MENU` array in the JavaScript section:

```javascript
const MENU = [
  {
    id: 1,
    name: "Food Name",
    price: 35000,
    image: "images/photo.jpg"
  }
];
```
